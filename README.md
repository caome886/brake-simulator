# 刹车模拟器

上帝视角 2D 驾驶小游戏：踩油门提速，踩刹车受力，**踏板受力达到 1600 N 会断裂**，随后弹出失败标语「遥遥领先」和重试按钮。

电脑、手机都能玩，纯单文件、无任何依赖、不需要联网。

## 怎么玩

方式一：直接双击 `index.html`。

方式二（推荐，和本机服务器一致）：在本目录启动自带静态服务器

```powershell
node serve.js
```

然后浏览器打开 → **http://127.0.0.1:8123/**

方式三：发布到网上（GitHub Pages + 国内可直连的镜像），见文末「发布到网上」。

### 电脑操作

| 操作 | 按键 |
| --- | --- |
| 加速 | `空格` / `↑` / `W` / 鼠标左键 |
| 刹车 | `↓` / `S` / 鼠标右键 |
| 重开 | `R`（失败界面也可点「重试」按钮） |

### 手机操作

- 屏幕底部有 **加速** / **刹车** 两个大按钮，按住生效、松开立即停止；**两个按钮可以同时按**（一根手指按住加速、另一根点刹车）。
- 也可以直接点画面：上半屏加速、下半屏刹车。
- 按钮在静止约 4 秒后自动淡出，把完整画面让出来；点一下屏幕（或右下角「操作」）就回来。
- 手机竖屏时上方会提示「横过手机玩，画面更大」；横屏时画面按可用高度自动铺满。
- 已锁定缩放/双击放大，并适配刘海屏安全区。

## 核心规则

- 油门：车速上升较快（约 4 秒到 100 km/h，表盘 0–240 km/h），路面标线随车速向后滚动。
- 刹车：**必须一直按住刹车键才有效**，松开立即停止施加刹车力（车速只受风阻/滚阻缓慢下降），踏板受力也在约 0.5 秒内归零。
- 按住刹车：脚立刻压到刹车踏板上；按住的**时间越久 → 踏板受力越大**（约 1.7 秒到 1600 N），车同步减速。
- 受力越大：踏板臂向防火墙方向弯曲、踏板橡胶面变红、屏幕边缘红光脉冲、出现警报音。
- **1600 N → 踏板断裂**：踏板臂在转轴下方折断、断口发红，橡胶踏板面连同下截臂飞出去落到地板上，火花四溅、屏幕震动 + 白闪、脚踩空垂下。
- 断裂后进入失败界面：大字「遥遥领先」+ 受力数据 + 绿色「重试」按钮。
- 想开快又不踩断踏板，就得**点刹**（按住、松开的节奏控制）。

## 画面构成

- 左：上帝视角路面 + 车辆（车轮、尾灯、刹车时尾灯发红）+ 拱形时速表（指针/刻度/数字读数/油门刹车状态灯）
- 右：**侧视脚踏视角**
  - **黑色皮鞋**：圆润鞋头、脚背起伏、鞋口、系带、皮革沿条与鞋跟块，轮廓带边光以便在暗环境里看出形状；鞋面用黑色皮革渐变 + 鞋头光泽高光。
  - **一只人的脚**：脚跟踩在地板上、前脚掌压在踏板面上、脚踝在脚跟后上方，小腿（深色西裤 + 裤缝受光）向后上方伸进画面外的大腿，裤脚下露出一点脚踝皮肤和深色袜口。
  - **悬挂式刹车踏板**：转轴支架、金属踏板臂（受力时向防火墙侧弯曲）、橡胶踏板面与防滑横纹。
  - 踩下时鞋尖**精确压在踏板面上**（接触点随踏板行程一起前移），踏板面上会出现受压高光；松开时脚尖沿踏板面法线抬起、离开踏板。
  - 底部是**实时受力数值（牛）**与阈值进度条。

## 开发/自测用参数（可选）

只在 URL 上加参数即可复现某个画面，方便截图与调试：

| 参数 | 作用 |
| --- | --- |
| `?speed=168` | 指定车速（画面静止） |
| `?speed=120&force=1400` | 指定车速与踏板受力（脚已踩下） |
| `?s=F700` | 直接呈现「踏板已断裂」画面 |
| `?go=3` | 直接呈现失败界面（含重试按钮） |
| `?anim=break` | 实时播放一次断裂动画 |
| `?sim=10&keys=Space,ArrowDown` | 确定性推进 10 秒模拟（自动化测试用） |

同时兼容 `#` 写法（`?force=1200` 与 `#force=1200` 等价），在会丢弃 query 的 CDN 上也能用。

自动化测试（无头 Chrome + CDP，逐步推进并断言状态）：

```powershell
node cdp-test.js          # 键盘/鼠标：加速曲线、按住刹车、松开归零、断裂、失败、重试
node cdp-mobile-test.js   # 手机仿真（390x844 触摸屏）：按钮、多点触控、重试、自动隐藏、横屏不遮挡
```

断言内容：加速曲线 → 按住刹车时受力增长并减速 → 松开后受力迅速归零（车速只剩滚阻）→ 1600 N 触发断裂、踏板面飞落 → 0.35 秒后进入失败态 → 点击「重试」按钮后状态完全复位。

手机端额外断言：识别为触屏设备、按钮尺寸够大（≥44px）→ 单指按加速 → **两指同按加速+刹车** → 抬指立即停止输入 → 单指刹车受力增长并减速 → 1600 N 断裂并进入失败界面 → 点画面重试复位 → 按钮栏自动隐藏 → 横屏时画面与按钮栏**零重叠**且点画面上半部识别为加速。

实测数据（无头 Chrome，1/120 秒步进）：

| 阶段 | 结果 |
| --- | --- |
| 只按油门 1 / 3 / 5 秒 | 24.4 / 70.6 / 93.5 km/h |
| 按住刹车 1 秒 | 受力 921 N，车速 93.5 → 66.0 km/h |
| 松开 0.1 / 0.4 秒 | 受力 668 → 0 N，车速仅按滚阻下降 |
| 持续按住 ~1.7 秒 | 受力 1600 N → 踏板断裂，4 块碎片飞落 |
| 断裂 +0.35 秒 | 进入失败界面，重试按钮出现 |
| 点击重试 | 状态完全复位（RESETS=1） |
| 手机竖屏 390×844 | 画面 358×209，按钮 179×110，画面完全在按钮栏上方 |
| 手机横屏 844×390 | 画面 480×280，与按钮栏零重叠 |

## 发布到网上

内置脚本用 GitHub API 建仓库、推送源码并开启 GitHub Pages（不需要安装 git）：

```powershell
# 1) 生成一个有 repo 权限的 token，存到 gh-token.txt（只放一行 token）
#    快捷链接：https://github.com/settings/tokens/new?scopes=repo,workflow&description=brake-simulator-deploy
# 2) 发布
node deploy.js                  # 仓库名默认 brake-simulator
node deploy.js my-repo-name     # 指定仓库名
node deploy.js --check          # 只验证 token
```

发布后会有三种链接：

| 链接 | 说明 |
| --- | --- |
| `https://github.com/<用户名>/<仓库>` | 源码仓库 |
| `https://<用户名>.github.io/<仓库>/` | GitHub Pages（国内访问不稳定） |
| `https://cdn.jsdelivr.net/gh/<用户名>/<仓库>@main/index.html` | CDN 镜像直链，国内通常可直连、免登录，打开即玩 |

`gh-token.txt` 已加入 `.gitignore`，不会被推送。

## 文件

- `index.html` —— 游戏本体（HTML + Canvas + WebAudio，单文件，含触屏操作）
- `serve.js` —— 仅用于本地预览的极简静态服务器
- `deploy.js` —— 一键发布到 GitHub（建仓库 + 推送 + 开 Pages）
- `cdp-test.js` —— 键盘/鼠标自动化行为测试
- `cdp-mobile-test.js` —— 手机触屏仿真测试
- `shots/` —— 各状态截图（含手机竖屏/横屏）
